# 决策阈值配置

所有 skill 共享此配置。修改此文件即可全局调整投资决策标准。

## 默认阈值（美股）

| 参数 | 变量名 | 默认值 | 说明 |
|------|--------|--------|------|
| 决策周期 | {HORIZON} | 24 months | 投资持有期预期 |
| 基准指数 | {benchmark} | S&P 500 | 业绩比较基准 |
| Alpha 目标 | {ALPHA_BPS} | +300 bps | 超额收益目标 |
| 预期回报门槛 | {HURDLE_TR_%} | 30% | 24 个月最低投资回报 |
| 安全边际 | {MOS_%} | 25% | 买入时要求的折扣 |
| 收益/回撤比 | {SKEW_X} | 1.7× | 风险调整后收益 |
| 质量分及格线 | {QUALITY_PASS} | 70 | 可投资的最低质量分 |
| 质量分卖出线 | {QUALITY_SELL} | 60 | 触发卖出的质量分 |

## 评级定义

| 评级 | 条件 | 行动建议 |
|------|------|---------|
| **Buy** | 4 道门控全部通过 + Quality ≥ 70 | 建仓或加仓 |
| **Hold** | 已持仓，当前价格合理 | 维持现有仓位 |
| **Await Entry** | 质量优秀但价格偏高 | 等待更好买点 |
| **Sell** | Quality < 60 或基本面恶化 | 减仓或清仓 |

## 4 道门控

1. **Expected Return Gate**: E[TR] ≥ {HURDLE_TR_%}
2. **Margin of Safety Gate**: 当前价格 ≤ 内在价值 × (1 - {MOS_%})
3. **Skew Gate**: E[TR] ÷ |Bear Drawdown| ≥ {SKEW_X}
4. **"Why Now" Gate**: {HORIZON} 内存在有日期的催化剂或重定价触发因素

任一门控未通过 → 评级不能为 Buy。
