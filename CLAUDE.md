## Development Guidelines

### Language
- Code: English (variables, comments, commits, PRs)
- UI/Content: Follow user's preference (Chinese or English)

### Git Workflow
- Branch from `main`
- Branch naming: `feat/<description>` or `fix/<description>`
- Commit messages: concise, imperative mood, English
- Run lint/test before committing

### Code Quality
- Keep it simple — minimal changes, minimal code
- No temporary fixes — find root causes
- Write tests for critical logic
- No secrets in code — use environment variables
