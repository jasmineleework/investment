# Investment — 个人投资研究与决策系统

一套面向**美股 / 港股**的个人投研工作台，以 Claude Code 插件形式实现。你用一句斜杠命令，就能自动拉取实时数据、跑估值模型、套用评级规则，产出一份结构化的投资研究备忘录。

全流程**只读**：负责研究、估值、晨报提醒——从不代下单。

## 能做什么

- **深度研究** — 输入 `/research NVDA`，产出机构级投资备忘录（基本面、估值、评级一应俱全）
- **快速筛查** — `/quick-check` 几分钟判断一只股票值不值得做完整研究
- **叙事选股** — 给一个投资主题，自动拆解受益链、发现候选股、按估值差排序
- **每日晨报** — 自选股新闻观点、当日发现、条件交易信号，可推送到 Telegram
- **复盘对比** — `/review` 对已研究标的重新评估，并和上一版做变化对比

## 斜杠命令

| 命令 | 作用 |
|------|------|
| `/research <ticker> [cn/en]` | 深度研究备忘录（基本面 + 估值 + 评级） |
| `/quick-check <ticker>` | ~5 分钟快速估值筛查，判断是否值得深研 |
| `/review <ticker>` | 重新评估已研究标的，附与上一版的变化对比 |
| `/narrative-screen <叙事>` | 从投资主题发现候选股，按估值差排序 |
| `/morning [--push]` | 10 分钟晨报，可推送 Telegram |

示例：

```
/research NVDA cn        # 英伟达中文深研备忘录
/research 0700.HK        # 腾讯（港股）
/quick-check AVGO
/narrative-screen "AI 数据中心电力供应链"
/morning --push
```

## 方法论

研究结论不靠"感觉"，而由一套固定纪律驱动：

- **数据实时抓取** — 估值与对比数据当天现取，不用近似值或记忆
- **估值先于叙事** — 先定合理价值区间，避免被故事带偏
- **多方法交叉验证** — DCF、WACC、质量打分、准入闸门共同决定评级
- **说人话** — 结论用中文清楚讲，不堆砌金融黑话

## 项目结构

```
investment-plugin/     # 插件本体
  ├── commands/        # 斜杠命令
  ├── skills/          # 技能模块（数据抓取 / 估值 / 质量打分 / 决策规则 / 晨报 …）
  └── references/      # 市场规则（美股/港股）、概念图、自选股模板
Research/              # 各标的研究产出（按 ticker 分目录，本地保存）
doc/                   # 设计文档
```

技能模块概览：数据抓取（三层源自动选优）、多方法估值、5 维商业质量打分、带准入闸门的评级引擎、叙事选股、晨报生成、moomoo 组合抓取、观察名单管理。

## 快速开始

1. 用 Claude Code 打开本项目目录，插件自动加载。
2. 复制 `investment-plugin/references/watchlist.json.example` 为自己的自选股清单。
3. 在对话里调用命令，如 `/research AAPL`。
4. 产出写入 `Research/<TICKER>/`，晨报写入 `Research/_morning/`。

### 环境依赖

- **Claude Code** — 运行宿主
- **Python 3.9+** 与 **uv / uvx** — 运行数据脚本与 MCP 服务
- **MCP 服务**：`yfinance`（行情财务）、`sec-edgar`（SEC 文件）
- 可选：**moomoo OpenD**（实时持仓）、**Telegram bot**（晨报推送）

---

> ⚠️ 本项目仅用于个人投资研究，产出不构成投资建议。所有命令均为只读，不执行任何交易或资金操作。
