# Investment — 会做投研纪律的 AI 分析师

> 把一句 `/research NVDA` 变成一份 40 页、机构级、可复现的深度研究备忘录。
> 面向**美股 / 港股**，以 Claude Code 插件形式实现。全流程**只读**——负责研究、估值、每日提醒，**从不代下单**。

大多数「AI 荐股」的问题不是不会写，而是**没有纪律**：数据靠记忆、估值挑对自己有利的、叙事先行、结论摇摆。这个项目把一套买方投研的硬纪律固化进流程，让 AI 像一个**风险优先、对价格挑剔的分析师**那样工作——而不是一个复读研报的聊天机器人。

## 先看产出，再决定要不要 star

两份真实生成的示例（数据均为生成当日实时抓取）：

- 📄 **[NVDA 深度研究备忘录](examples/research-report-nvda-2026-07-14.md)** — 21 节 + 估值三角化 + 评级闸门。结论是 **Await Entry（观望）而非 Buy**：一份「质疑价格、而非质疑公司」的报告。含 DCF / 可比 / 逆向 DCF 交叉验证、Valuation Football Field、Bear/Base/Bull 情景、与卖方共识的分歧归因（**$170 vs 共识 $301，分歧根源单一且清晰：折现率**）。
- 📄 **[TPU 叙事筛选报告](examples/narrative-report-tpu-2026-07-14.md)** — 从「Google 靠自研 TPU 垂直整合」一个主题出发，拆出 L1/L2/L3 受益链，16 只候选筛到 5 只并排序。**还告诉你哪些是认知陷阱**：照 GPU 供应链买 Micron 是错的（TPU 的 HBM 用三星/海力士，Micron 基本不在链内）。

这两份报告主题天然呼应：一份讲 AI 算力的「卖铲人」，一份讲「谁在分食卖铲人」。

## 它凭什么不一样：纪律，而非话术

| 常见 AI 荐股 | 本项目 |
|---|---|
| 数据靠模型记忆 / 「约」「近似」 | **所有估值与对比数据当天实时抓取**，禁止估计值 |
| 先讲故事，再找数字凑 | **估值先于叙事**：先定合理价值区间，避免被叙事锚定 |
| 换到满意为止的 DCF | **单模型原则**：一套假设产出一个公允价值，不反复调参 |
| 只给「看涨」结论 | **四道准入闸门**（回报 / 安全边际 / 赔率 / 催化剂），过不了就是 Await Entry |
| 每次结论飘忽 | **跨报告 Delta 校验**：同标的短期估值差 >20% 且无新数据即判定漂移 |
| 满屏英文黑话 | 结论用中文讲清楚，术语首次出现给白话解释 |

这些不是 README 里的口号——上面两份示例逐条体现了它们。

## 五个命令覆盖完整投研闭环

| 命令 | 作用 | 什么时候用 |
|------|------|-----------|
| `/research <ticker> [cn/en]` | 机构级深度备忘录（基本面 + 估值 + 评级） | 认真研究一只票 |
| `/quick-check <ticker>` | ~5 分钟快速估值筛查 | 判断值不值得深研 |
| `/narrative-screen <叙事>` | 从主题发现候选股、按估值差排序 | 有个主题想找标的 |
| `/review <ticker>` | 重新评估已研究标的 + 变化对比 | 财报后 / 定期复盘 |
| `/morning [--push]` | 10 分钟晨报，可推送 Telegram | 每天开盘前 |

示例：

```
/research NVDA cn                    # 英伟达中文深研备忘录
/research 0700.HK                    # 腾讯（港股）
/narrative-screen "Google TPU 供应链"  # 主题选股
/quick-check AVGO
/morning --push                      # 晨报推送到 Telegram
```

## 快速开始

1. 用 Claude Code 打开本项目目录，`investment-plugin/` 会自动加载。
2. 复制 `investment-plugin/references/watchlist.json.example` 为自己的自选股清单。
3. 在对话里调用命令，如 `/research AAPL`。
4. 深研产出写入 `Research/<TICKER>/`，晨报写入 `Research/_morning/`。

### 环境依赖

- **Claude Code** — 运行宿主
- **Python 3.9+** 与 **uv / uvx** — 运行数据脚本与 MCP 服务
- **MCP 服务**：`yfinance`（行情财务）、`sec-edgar`（SEC 文件），已在 `.mcp.json` 配好
- 可选：**moomoo OpenD**（拉取实时持仓）、**Telegram bot**（晨报推送）

## 项目结构

```
investment-plugin/     # 插件本体
  ├── commands/        # 5 个斜杠命令
  ├── skills/          # 技能：数据抓取 / 估值 / 质量打分 / 决策规则 / 叙事选股 / 晨报 …
  └── references/      # 市场规则（美股/港股）、概念图、自选股模板
examples/              # 示例报告（研究 + 叙事），供参考
Research/              # 你的研究产出（按 ticker 分目录，本地保存）
```

技能各司其职、可组合：数据抓取（三层源自动选优）→ 质量打分（5 维 0–100）→ 多方法估值（DCF/WACC）→ 决策规则（4 道闸门给评级），叙事选股与晨报在其上编排。

---

> ⚠️ 本项目仅用于个人投资研究，产出不构成投资建议。所有命令均为只读，不执行任何交易或资金操作。示例报告为特定日期的历史快照，数据与结论已过时，仅用于展示方法论。
