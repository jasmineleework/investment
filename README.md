# Investment — 个人投资研究与决策系统

这是一套面向美股与港股的个人投资研究工作台。它的目标是把一次深度研究所需的全部工作——数据采集、财务分析、估值建模、评级判断——固化为可复现的标准流程，让人只用一句命令就能得到一份结构完整、有据可依的投资研究备忘录。

## 示例报告

以下两份是系统真实生成的示例，其中所有数据均为生成当日实时抓取，可以直接查看以了解产出的深度与风格：

- **[NVDA 深度研究备忘录](examples/research-report-nvda-2026-07-14.md)**：一份包含 21 个分析章节、估值三角化与评级闸门的完整备忘录。它给出的结论是「观望入场」而非「买入」，核心是质疑当前价格而非质疑公司质量。报告采用 DCF、可比公司、逆向 DCF 三种方法交叉验证公允价值，并逐条说明了自身估值（每股 170 美元）与卖方共识（301 美元）之间的分歧根源在于折现率的选择。
- **[TPU 叙事筛选报告](examples/narrative-report-tpu-2026-07-14.md)**：从「Google 依靠自研 TPU 实现垂直整合」这一投资主题出发，拆解出三层受益链条，将 16 只候选标的筛选并排序为 5 只。报告不仅给出排名，也指出了其中的认知陷阱，例如照搬 GPU 供应链去买入 Micron 是错误的，因为 TPU 使用的高带宽内存主要由三星与海力士供应，Micron 基本不在该链条内。

## 数据源整合

整合权威数据源：
- **yfinance**：美股与港股股票行情与财务报表数据和新闻
- **SEC EDGAR**：美股公司的招股与定期报告原文（10-K、10-Q）以及内部人交易记录
- **FRED**：利率等宏观经济数据，用于估值中的折现率与情景假设
- **akshare**：港股与A股财报数据与新闻
- **moomoo OpenAPI**：接入moomoo实时持仓与行情快照，用于持仓组合分析


## 命令一览

系统提供五个斜杠命令，覆盖从主题发现到深度研究再到定期复盘的完整流程：

| 命令 | 作用 |
|------|------|
| `/research <ticker> [cn/en]` | 生成机构级深度研究备忘录，涵盖基本面、估值与评级 |
| `/quick-check <ticker>` | 约五分钟的快速估值筛查，用于判断是否值得投入完整研究 |
| `/narrative-screen <叙事>` | 从一个投资主题出发发现候选标的，并按估值差距排序 |
| `/review <ticker>` | 对已研究过的标的重新评估，并与上一版报告做变化对比 |
| `/morning [--push]` | 生成约十分钟阅读量的晨报，可选择推送至 Telegram |

使用示例：

```
/research NVDA cn                      # 生成英伟达的中文深度备忘录
/research 0700.HK                      # 研究腾讯（港股）
/narrative-screen "Google TPU 供应链"   # 围绕一个主题筛选标的
/quick-check AVGO
/morning --push                        # 生成晨报并推送到 Telegram
```

## 快速开始

1. 使用 Claude Code 打开本项目目录，`investment-plugin/` 会自动加载。
2. 将 `investment-plugin/references/watchlist.json.example` 复制为自己的自选股清单。
3. 在对话中调用命令，例如 `/research AAPL`。
4. 深度研究的产出会写入 `Research/<TICKER>/`，晨报会写入 `Research/_morning/`。

运行环境需要 Claude Code 作为宿主，Python 3.9 及以上版本与 uv/uvx 用于运行数据脚本和 MCP 服务。项目已在 `.mcp.json` 中配置好 yfinance（行情与财务数据）和 sec-edgar（SEC 文件）两个数据服务。若需要拉取实时持仓，可另行配置 moomoo OpenD；若需要推送晨报，可配置 Telegram 机器人。

## 项目结构

```
investment-plugin/     插件本体
  ├── commands/        五个斜杠命令
  ├── skills/          技能模块：数据抓取、估值、质量打分、决策规则、叙事选股、晨报等
  └── references/      市场规则（美股/港股）、概念图、自选股模板
examples/              示例报告（深度研究与叙事筛选），供参考
Research/              研究产出，按标的分目录保存在本地
```

各技能模块各司其职并可相互组合：数据抓取模块按三层策略自动选择最佳可用数据源，质量打分模块从五个维度给出 0 至 100 分的商业质量评分，估值模块以多种方法产出公允价值区间，决策规则模块依据四道闸门给出最终评级，叙事选股与晨报则在这些模块之上进行编排。

---

本项目仅用于个人投资研究，其产出不构成投资建议。所有命令均为只读，不会执行任何交易或资金操作。示例报告是特定日期的历史快照，其中的数据与结论均已过时，仅用于展示方法论。
